title: Describe each project, and read the user guide inside Kara
---

Each project now has a description, and the user guide lives in the app next to the release notes.

- **A description on every project.** A project's page opens with Description: a few lines on what the project is and why it matters. Write it right there; Kara saves it in the project's Objective field in Notion, so it also shows in Notion, and anything written there shows in Kara.
- **The user guide, inside Kara.** Settings now has "User guide" next to "See all updates", and the Updates screen has it at the top. The guide covers today's Kara end to end: Today, the paper, meetings, Projects and project pages, Review, Days, Triage and Timer. A side index jumps to any section.
- **One guide, everywhere.** The guide ships with the app, so it matches the version you run and reads offline. The Agent Hub publishes the same text.
