title: Next actions reach Notion, each on its own project
---

Your projects loaded, but a new next action failed with "Invalid agent URL", and one action showed under every project. Notion changed two formats, and Kara now follows both.

- **Next actions save in Notion.** Notion now expects a person in a new form. Kara sends you as the assignee that way, so the action lands in your Next Actions.
- **Each project keeps its own actions.** Notion now gives page links on app.notion.com. Kara only read the old notion.so links, so every project looked like the same one. Both link forms work now.
- **A shorter error.** When Notion refuses something, the banner shows only Notion's sentence, not the raw reply.

An action you added before this update (like "finish presentation") was saved without a project. It goes to your Next Actions in Notion with no project: file it there, or delete it and add it again in Kara.
