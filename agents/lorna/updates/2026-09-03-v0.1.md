Lorna was created as an agent on the Mac mini, with her operating rules built in from day one.

- **Agent live.** Lorna runs on the always-on Mac mini with her operating rules built in.
- **Ledger designed and live.** The system of record for every document lives on local disk, with filing and payment tracking fully decoupled.
- **Rules written first.** Tool contracts and the permission matrix were written before any automation; the state machine was revised to v2.
- **Archive audit done.** Enough historical documents exist to build the evaluation corpus, and almost all recent documents are already text-searchable.
